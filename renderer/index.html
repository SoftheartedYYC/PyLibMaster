PyLibMaster
v0.1.0-alpha
作者: SoftheartedYYC
联系方式: softheartedyyc@gmail.com
项目地址: github.com/SoftheartedYYC/PyLibMaster
PyLibMaster 是一款基于 Electron 的 Python 库图形化管理工具，提供库的安装、卸载、更新、查询，多环境切换、镜像源管理与备份回滚等功能，让 Python 第三方库的管理更加简单高效。
使用声明 本软件为免费开源工具，仅供个人学习与研究使用，不得用于任何商业用途，禁止以任何形式进行收费或变相收费。
