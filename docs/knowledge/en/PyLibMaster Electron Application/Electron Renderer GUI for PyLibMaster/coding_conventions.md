- Global shared state (installedLibs, updateLibs, mirrors, envs, logData, progress flags, selected sets) is declared as top-level `let` variables in `core.js` and accessed directly by all other modules without imports or exports.
- User-facing text is localized via the `t(key)` function that looks up keys in `window.I18N[currentLang]`, with `data-i18n` and `data-i18n-placeholder` attributes on HTML elements driving i18n application.
- DOM event handlers are attached in `app.js` using `addEventListener` on selectors, while inline `onclick="..."` attributes are used only for simple one-liner actions defined globally (e.g., `startInstall()`, `cancelCurrentOperation()`).
- Table rendering functions follow a consistent pattern: read filter/sort state from DOM inputs, compute a filtered list, set empty-state visibility, and assign `innerHTML` via template literals with `escapeHtml()` on every user-supplied string.
- Long-running operations expose a unique `operationId` generated by `generateOperationId()` and stored in `currentOperationId`, enabling cancellation through `api.cancelPipOperation(operationId)`.
- Progress updates flow from the main process via `api.onProgress(callback)` registered once in `app.js`, with `progress.js` functions (`resetProgress`, `finishProgress`) updating the shared progress UI.
