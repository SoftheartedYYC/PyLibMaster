Single-page Electron renderer built from one `index.html` plus eight sequential JS modules loaded in dependency order: `i18n.js` (translation dictionary) → `core.js` (global state + `window.electronAPI` bridge + shared utilities like `escapeHtml`, `showToast`, `generateOperationId`) → `render.js` (table rendering for uninstall/update/query/mirrors/env/logs/stats) → `progress.js` (progress bar UI) → `operations.js` (install/uninstall/update orchestration with cancel support) → `pages.js` (page-specific interactions) → `app.js` (event binding, keyboard shortcuts, startup bootstrap). All modules share global variables declared in `core.js` rather than using ES modules. The HTML defines nine `<div class="page">` sections (`install`, `uninstall`, `update`, `query`, `templates`, `pypi`, `logs`, `dashboard`, `tools`, `settings`, `about`) toggled via sidebar `data-page` attributes. Cross-process communication goes exclusively through the preloaded `window.electronAPI` object; no direct Node.js access. Static assets live under `assets/` and styles are centralized in `styles.css`.
