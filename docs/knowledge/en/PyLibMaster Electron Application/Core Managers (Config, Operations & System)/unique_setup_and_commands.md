No build step — modules are loaded directly by the Electron app. Some functionality requires platform-specific setup: Windows explorer context menu registration writes to `HKCU\Software\Classes\Directory\Background\shell\PyLibMaster` via `reg add`; pip config is written to `%APPDATA%/pip/pip.ini` (Windows) or `~/.config/pip/pip.conf` (macOS/Linux); Python environments are auto-detected from common paths including Conda/Miniconda locations.
