Node.js CommonJS modules running inside Electron (`require('electron').app` for userData paths); uses `glob` for cross-platform Python path discovery, native `fs`/`path`/`os` for filesystem access, `child_process.execSync` for Windows registry manipulation, and `fetch` with `AbortController` for mirror speed testing. External tools invoked include `pip`, `pip-audit`, `python -m ensurepip`, and `where python`.
