The root is an Electron app whose `main.js` entry bootstraps a BrowserWindow with context isolation and no Node integration, loads `preload.js` as a security bridge, and registers every `ipcMain.handle` channel. The renderer (`renderer/`) calls methods on `window.electronAPI` exposed by `preload.js`, which forwards each call via `ipcRenderer.invoke` to a matching handler in `main.js`. Those handlers import and delegate to the `core/` modules (pipManager, mirrorManager, envManager, backupManager, logManager, configManager, updater, venvManager, schedulerManager, templateManager, auditManager, undoManager, explorerManager) and push progress back to the renderer through one-way channels like `pip:progress`, `theme:changed`, `updates:available`, `scheduler:executed`. Tests under `tests/` bootstrap against this same IPC surface using mocked core managers, keeping the three layers—renderer, main/preload bridge, core—strictly separated.
