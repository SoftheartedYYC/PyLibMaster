- IPC 通道统一采用 '领域:动作' 命名规范（如 pip:install、mirror:testAll、scheduler:save），主进程通过 ipcMain.handle 注册，预加载脚本通过 ipcRenderer.invoke 调用
- 长耗时异步操作通过回调参数接收 (data, type) 并经由 event.sender.send('pip:progress', { operation, data, type }) 推送实时进度到渲染进程
- 主进程对渲染进程暴露的 API 严格通过 contextBridge 白名单方式声明，禁止直接访问 Node.js 原生 API
- 外部路径打开统一经 utils/security.isAllowedOpenPath 校验，仅允许 documents/downloads/userData 三个目录下的文件
