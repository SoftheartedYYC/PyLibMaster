- 每个 manager 文件采用函数式导出（`module.exports = { ... }`），模块内状态通过闭包变量 + 惰性 `init()` 初始化，读取接口返回深拷贝防止外部修改内部状态
- 对外部输入进行严格校验：包名使用正则 `VALID_PACKAGE_NAME`，版本号使用 `VALID_VERSION_SPEC`，wheel 路径禁止 `..`、UNC 路径和敏感目录，备份 ID 使用白名单匹配
- 所有 pip 操作通过 `utils/processRunner` 的 `runPip`/`runCommand` 执行，并传入 `onOutput` 回调和 `operationId` 用于进度上报与取消操作
- 错误处理统一通过 `logManager.addLog({ action, status, type, detail })` 记录，失败时抛出带明确消息的 `Error`，关键路径使用 try/catch 包裹并降级到 `console.error`
- 需要磁盘写操作的模块采用原子写入策略：先写 `.tmp` 文件再 `renameSync` 替换，或写入前创建备份目录并通过 `mkdirSync(dir, { recursive: true })` 确保存在
- 耗时操作支持并发控制：`pipManager` 使用 `acquireEnvLock` 基于 Promise 的环境级互斥锁，`runInParallel` 实现有界并发队列，`mirrorManager.testAllMirrors` 使用 `Promise.all` 并行测速
