采用标准 Electron 三进程架构：main.js 作为主进程入口，负责创建 BrowserWindow、注册所有 ipcMain.handle 处理器、管理应用生命周期（启动/退出/托盘/主题同步）；preload.js 通过 contextBridge.exposeInMainWorld 暴露 window.electronAPI，将渲染进程的调用安全转发到主进程；renderer/ 为前端界面，core/ 为 Node.js 后端逻辑。IPC 通道按功能域命名（window:、env:、pip:、backup:、mirror:、log:、config:、updater:、scheduler:、template:、snapshot:、audit:、undo:、explorer:），长耗时操作通过 event.sender.send('pip:progress', ...) 推送进度事件给渲染进程。electron-builder 配置在 package.json 中打包为 Windows NSIS 安装包，并通过 electron-updater 发布到 GitHub Releases。
