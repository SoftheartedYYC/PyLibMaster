模块为纯静态 Web 前端，由 index.html 作为唯一入口，通过 script 标签按严格顺序加载 js/ 下的六个 JS 文件：i18n.js → core.js → render.js → progress.js → operations.js → pages.js → app.js。核心分层如下：
- i18n.js：注册 window.I18N 全局字典，提供 t(key) 翻译函数。
- core.js：集中定义所有全局共享状态（installedLibs、updateLibs、mirrors、envs、logData、进度变量等）和通用工具（escapeHtml、showToast、generateOperationId），并通过 window.electronAPI 桥接主进程。
- render.js：负责表格渲染与选择逻辑（卸载/更新/查询/镜像/环境/日志/统计卡片）。
- operations.js：封装安装、卸载、更新三大操作的生命周期（进度、取消、刷新、通知）。
- pages.js：镜像源、环境、日志、设置、自动更新等页面交互。
- tools.js：工具箱子功能（依赖图谱 Canvas 力导向图、磁盘分析、环境对比、离线下载、撤销、系统集成）。
- app.js：事件绑定与启动初始化，采用三阶段异步加载（Phase 1 并行快速数据、Phase 2 后台刷新、Phase 3 懒加载）保证首屏响应。
HTML 中每个页面以 id="page-xxx" 的 div 表示，侧边栏通过 data-page 属性驱动切换；CSP 限制仅允许 self 脚本与内联样式，通过 window.electronAPI 与主进程通信。
