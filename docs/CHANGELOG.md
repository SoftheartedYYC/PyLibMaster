# PyLibMaster 更新日志

## 版本说明

采用 [Semantic Versioning](https://semver.org/lang/zh-CN/) 规范：

- **主版本号（Major）**：破坏性变更或不兼容的 API/交互改动。
- **次版本号（Minor）**：新增功能、非破坏性增强。
- **修订号（Patch）**：Bug 修复、细节优化。

---

## [1.5.23] - 2026-08-01

### 架构重构

- `core/` 目录三类划分：`config/`（配置管理）、`operations/`（核心操作）、`system/`（系统服务），职责边界更清晰。
- `renderer/` 前端拆分为 8 个独立 JS 模块：`app.js`（初始化）、`core.js`（工具函数）、`i18n.js`（国际化）、`operations.js`（操作逻辑）、`pages.js`（页面渲染）、`progress.js`（进度管理）、`render.js`（表格渲染）、`tools.js`（工具箱）。
- 静态资源统一迁移到 `renderer/assets/`。

### 新增模块

- `auditManager.js`：基于 pip-audit 和 PyPI Advisory Database 的安全漏洞扫描。
- `templateManager.js`：环境快照与项目模板，支持一键创建虚拟环境。
- `undoManager.js`：操作撤销，支持回滚最近一次安装/卸载/更新。
- `venvManager.js`：Python venv 虚拟环境的创建、删除与管理。
- `schedulerManager.js`：定时自动更新调度器，支持配置更新频率。
- `explorerManager.js`：Windows 资源管理器右键菜单集成。
- `logManager.js`：重构为结构化日志系统，支持导出。
- `configManager.js`：新增配置校验与原子写入。

### 功能增强

- `pipManager.js` 大幅扩展（+932 行）：新增依赖图谱、空间分析、环境对比、离线下载、文件批量安装。
- `envManager.js` 扩展：新增 Anaconda/Miniconda/Windows Store 环境检测。
- `mirrorManager.js` 扩展：新增拖拽排序、测速智能路由。
- `main.js` 大幅扩展（+496 行）：接入所有新模块的 IPC handler。
- `preload.js` 扩展（+146 行）：暴露新增功能的 IPC 接口。

### 工程化

- 新增 `.github/workflows/ci.yml`：GitHub Actions CI/CD 流水线，自动构建与发布。
- `utils/processRunner.js` 扩展：支持任务取消、ANSI 清理增强。
- `utils/security.js` 新增：路径安全校验纯函数模块。

## [1.5.12] - 2026-07-29

### 安全修复

- 修复 `pipManager.uninstallPackages` 未校验包名的问题，防止卸载时注入非法参数。

### 可靠性增强

- 修复 `preload.js` 中 `onProgress` 事件监听器内存泄漏：每次重新注册前先移除旧的 `pip:progress` 监听器。
- 实现应用退出时的 graceful shutdown：在 `before-quit` 中调用 `cancelAllProcesses` 清理活跃子进程，避免孤儿进程。
- 统一关键路径错误处理风格：`pipManager`、`mirrorManager` 中的缓存/目录/配置写入失败统一使用 `logManager.addLog` 记录。

### 代码质量

- 升级 `glob` 到 `^11.0.0`，并将 `envManager.js` 改为使用新的 Promise API。
- `sitePackagesCache` 改为按 `pythonPath` 隔离的 `Map`，切换 Python 环境不再使用旧缓存。
- `getFolderSizeCached` 增加递归深度上限（`MAX_DEPTH = 20`），防止符号链接循环或极深目录导致栈溢出。
- 将 `package.json` 中的 JSON 注释 `"// strip-ansi"` 迁移到合法的 `dependencyNotes` 字段。
- 新增 `utils/security.js` 纯函数模块，提升 `isAllowedOpenPath` 的可测试性。

### 测试

- 新增基础单元测试 `tests/core.test.js`，使用 Node 内置 `node:test` 覆盖 `buildPackageSpec`、`validateBackupId`、`isAllowedOpenPath`、`buildPackageDirMap`、`estimatePackageSizeFast`。

## [1.5.8] - 2026-07-29

### 性能优化

- 优化 `listInstalled` 性能：缓存 `site-packages` 路径、批量建立包名→目录映射表、消除循环内的 `glob.sync`。
- 镜像源测速改为 `Promise.all` 并行执行，总耗时降至最慢源响应时间。

### 可靠性增强

- 修复 `processRunner.js` 超时 timer 未清理的问题，超时触发 `SIGTERM` 后 5 秒未退出再 `SIGKILL` 兜底。
- 为 `pipReadyCache` 增加 5 分钟 TTL，避免 pip 损坏后缓存误导。
- 为并行 pip 安装添加环境级互斥锁，防止同一环境多进程写入冲突。
- 新增 pip 操作取消功能：安装/卸载/更新任务支持通过前端“取消”按钮中止。

## [1.2.0] - 2026-07-28

### 新增功能

- **更新库支持并行更新**：`updatePackages` 现在与 `installPackages` 一样，可按设置里的"并行线程数"分批同时更新多个库。
- **更新库支持智能重试**：单个库更新失败时，自动切换到下一个镜像源重试。
- **更新选项面板**：更新页新增"并行更新"、"智能重试"、"更新失败自动回滚"三个复选框，用户可自由组合策略。
- **全部更新不影响分批策略**：无论勾选几个库还是点击"全部更新"，都会按线程数分批执行，单包失败不影响同批其他包。

### 优化与修复

- 修复 `updatePackages` 一次性把所有包交给单个 pip 命令执行、无法利用多线程的问题。
- 修复更新完成后界面提示不够准确的问题，现在会显示失败包数量。

## [1.1.0] - 2026-07-28

### 新增功能

- **Electron 应用主体**：完成主进程（main.js）、预加载脚本（preload.js）与核心模块（pip/env/mirror/backup/config/log/processRunner）的搭建。
- **前端接入真实 IPC API**：移除 mock 数据，安装/卸载/更新/查询/环境切换等操作全部调用后端接口。
- **进度与日志**：长任务实时输出进度，操作日志可查看、筛选、清空。
- **环境检测**：自动扫描系统 Python 环境，未检测到时显示红色状态点并清空默认统计。
- **设置持久化**：主题、语言、并行线程数、重试次数、存储路径等配置自动保存。
- **镜像源备注**：自定义镜像源支持添加备注，列表中显示在地址下方。
- **镜像源编辑**：所有镜像源（含内置源）均支持原地编辑名称、地址和备注；若修改内置源地址，则自动转为自定义源。
- **自定义镜像源名称**：添加自定义镜像源时可手动填写名称，留空则自动使用域名。
- **恢复默认镜像源**：在设置页新增“恢复默认镜像源”按钮，重置内置镜像源并保留自定义镜像源。
- **标题栏改造**：移除标题栏中的“PyLibMaster”文字与左侧三色圆点，将 Logo 移至标题栏左侧，标题栏背景随主题切换。

### 优化与修复

- 修复 `envManager.js` 缺少 `runCommand` 导入的问题。
- 修复 `strip-ansi` ESM 不兼容问题，降级到 `^6.0.1`。
- 补充 `glob` 依赖，确保环境扫描正常。
- 配置 `electron-builder` 使用 npmmirror 镜像，关闭签名验证，避免普通用户权限下打包失败。
- 初始化流程改为各接口独立 `try/catch`，即使某个接口失败也能渲染空状态，避免界面卡死。
- 默认统计数值由占位值改为 `0`，未检测到环境时不再显示误导数据。
- 语言切换后自动重新渲染所有动态表格与文案。
